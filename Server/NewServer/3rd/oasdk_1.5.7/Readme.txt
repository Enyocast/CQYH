SDOA_SDK  Version SDOA_SDK_CSO.1.5.7.20100407.VSL
(2010-04-12)
===============
概述
-------------
本产品为盛大在线推出一系列包括圈圈、认证、计费等服务的产品。本SDK包括本产品接入应用所需的程序组件与示例、演示、文档。
 
目录说明
-------------
 |-  Client               //客户端模块
 |   |-  bin              // IGW客户端模块程序文件
 |   |-  Samples          //各种渲染技术下的应用接入IGW范例
 |   |-  SDK              //头文件
 |   |-  Tools		  //工具
 |-  Server               //服务端模块
 |   |-  linux            //linux环境组件
 |   |   |-  bin          //程序文件
 |   |   |-  samples      //模块接入范例代码
 |   |-  win32            //windows环境组件
 |   |   |-  bin          //程序文件
 |   |   |-  samples       //模块接入范例代码
 |-  DEMO                  //演示程序
 |   |-  GameClient(IGW)   // IGW演示程序

 接入配置说明
-------------
1、如需运行SDK中的DEMO，必须有访问公网的环境，至少可以访问如后IP：210.51.30.84, 210.51.31.208,210.51.31.209;
2、开始本产品接入开发前，请到本产品官方网站 http://open.sdo.com上注册用户，获得商务编号（SPID），注册您要接入的应用，获得应用编号（AppID）;
3、调试您的产品接入代码前，请到本产品官方网站http://open.sdo.com上的开发平台登记您的服务器信息。
4、调试和测试您的接入代码时，请确保程序运行环境能访问公网，至少可以访问如后IP：210.51.30.84, 210.51.31.208,210.51.31.209;
5、上线运营您的应用前，请到本产品官方网站http://open.sdo.com上的运营平台登记您的服务器信息。

OA统一配置系统是为了配合OA系统组件灵活的获取所需的配置为初衷而设计开发的一套辅助系统。该系统服务端使用http服务器提供一个http请求服务，客户端有C++开发封装到sdoa4server组件中，供游戏服务器透明调用。
