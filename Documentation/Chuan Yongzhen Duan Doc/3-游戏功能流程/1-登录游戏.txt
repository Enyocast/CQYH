

1, [客户端] 发包 [c2t_login_req] 申请 登录游戏 (本例登录端口 8701)
{
	start MMOGame-Win32-Shipping.exe -sdot -ip=1,1,192.168.48.1,8701,192.168.48.1,8701,Legend
	start MMOGame-Win32-Shipping.exe -sdot -ip=1,1,192.168.48.1,8702,192.168.48.1,8702,Legend
	
	看连接的IP, 打开系统工具 资源监视器 => 侦听端口界面, 找到进程名字, 查看对应的IP和端口, 单机搭建IP 不是 127.0.0.1

	一般情况下, 两个端口都能登录上来
	balanceserver => 8701
	gateserver => 8702
}
